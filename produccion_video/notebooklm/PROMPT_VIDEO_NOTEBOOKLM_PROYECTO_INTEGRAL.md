# Prompt para Video Overview — proyecto integral LIVINN

Crear un video explicativo horizontal en español latino, claro, profesional y dinámico, de aproximadamente 3 a 4 minutos. Debe funcionar como caso de estudio académico para Raúl y explicar el proyecto completo de LIVINN, equilibrando el trabajo de Iván y Miguel.

Estructura narrativa:

1. Abrir con el problema: presentar las cabañas, ordenar consultas y administrar una reserva sin mezclar la web pública con sistemas privados.
2. Explicar la solución integral en cuatro capas: web, WhatsApp, agente automatizado y control humano.
3. Mostrar la contribución de Iván: 23 posiciones visuales, cuatro unidades, experiencia responsive, accesibilidad, formulario estructurado, pruebas, GitHub, respaldos y publicación en Vercel.
4. Mostrar el puente: la web prepara nombre, unidad, fechas, huéspedes y comentario, y abre WhatsApp. La landing no se conecta directamente con Calendar o Sheets.
5. Explicar la contribución de Miguel: VPS, Docker/Dokploy, Hermes, WhatsApp, OpenRouter y MCP de Composio con aplicaciones autorizadas.
6. Representar exactamente el flujo confirmado: reunir datos → consultar disponibilidad en Calendar → presentar cotización y resumen → esperar confirmación explícita → registrar primero en Sheets → crear evento en Calendar → enviar correo por Gmail → mantener pago bajo validación administrativa.
7. Explicar el trabajo conjunto, el uso responsable de agentes de IA, las auditorías, los respaldos y la producción de publicidades.
8. Cerrar con el resultado: una experiencia clara para el huésped y una base operativa organizada, con responsabilidades separadas y revisión humana.

Usar un tono de presentación ganadora pero sobria. Priorizar capturas reales sanitizadas, interfaz del sitio, mapa conceptual, iconos de WhatsApp, Calendar, Sheets, Gmail, GitHub y Vercel. Evitar pantallas genéricas que contradigan las fuentes.

Nombrar y atribuir correctamente:

- Iván: web, integración visual, UX responsive, accesibilidad, formulario, QA, GitHub, Vercel, documentación y producción audiovisual.
- Miguel: VPS, Docker/Dokploy, Hermes, WhatsApp, MCP de Composio, Calendar, Sheets, Gmail y reglas operativas.

No inventar métricas, clientes, testimonios, ingresos, reservas reales ni funciones. No afirmar que la web confirma disponibilidad, procesa pagos o accede directamente a Google. No afirmar protección absoluta contra solicitudes simultáneas. No revelar datos personales, credenciales, rutas internas, endpoints ni identificadores.

Finalizar agradeciendo a Raúl y presentando LIVINN como un MVP académico construido en equipo, documentado y preparado para seguir evolucionando.
