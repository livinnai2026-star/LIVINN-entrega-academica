# Prompt para Video Overview — parte de Iván

Crear un video explicativo en español latino, claro y profesional, de aproximadamente 2 a 3 minutos.

El video debe centrarse exclusivamente en la contribución de Iván a LIVINN: construcción de la experiencia web, integración de 23 posiciones visuales, experiencia móvil y desktop, accesibilidad, formulario estructurado de WhatsApp, pruebas, GitHub, respaldos, Vercel y documentación audiovisual.

Estructura sugerida:

1. Problema y objetivo del MVP.
2. Cómo se construyó y organizó la web.
3. Recorrido del huésped y experiencia responsive.
4. Cómo la web prepara la consulta para WhatsApp.
5. Pruebas, accesibilidad, versiones y publicación.
6. Resultado y aporte de Iván dentro del equipo.

Usar un tono de caso de estudio académico, dinámico pero sobrio. Priorizar diagramas, capturas, interfaz, imágenes de cabañas y relaciones visuales entre web, WhatsApp, GitHub y Vercel.

No profundizar en la infraestructura de Miguel. Mencionarla únicamente para explicar que, después de WhatsApp, comienza una automatización separada desarrollada por él.

No afirmar que la landing consulta Google Sheets o Calendar, confirma reservas, procesa pagos o garantiza disponibilidad. No inventar métricas, fechas, testimonios ni funciones. No exponer datos sensibles.

Cerrar explicando que la web convierte una propuesta turística en una experiencia digital clara, verificable y preparada para conectarse con la atención operativa.
