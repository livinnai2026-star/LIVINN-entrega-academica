# Capturas sanitizadas — flujo operativo LIVINN

Estas cinco imágenes son copias preparadas para el repositorio académico y para NotebookLM. Los originales permanecen fuera del repositorio.

## Secuencia

1. `01_whatsapp_disponibilidad_sanitizada.png`: consulta de disponibilidad y alternativas.
2. `02_whatsapp_confirmacion_sanitizada.png`: confirmación explícita y resultado del registro.
3. `03_calendar_reservas_sanitizado.png`: evidencia de ocupación en Calendar.
4. `04_sheets_reserva_sanitizada.png`: estructura del registro operativo en Sheets.
5. `05_gmail_confirmacion_sanitizada.png`: correo de confirmación con pago y reserva pendientes de validación.

## Transformaciones realizadas

- Nombres sustituidos por `Huésped Demo`.
- Correos personales sustituidos por `huesped.demo@example.com` o `demo@example.com`.
- Teléfonos personales sustituidos por valores de demostración.
- IDs de reserva sustituidos por `LIV-DEMO-*`.
- IDs de eventos sustituidos por `DEMO-EVENT-*`.
- Nombres internos de herramientas ocultos con la etiqueta `Automatización ejecutada`.
- Otras reservas visibles anonimizadas.

El número de WhatsApp de LIVINN y el correo público del proyecto se conservaron porque ya forman parte de la comunicación pública del sitio.

## Uso responsable

Las imágenes documentan el flujo y la forma de las interfaces, pero sus datos identificatorios fueron reemplazados. Deben describirse como **capturas sanitizadas de una prueba controlada**, no como registros literales de huéspedes reales.
