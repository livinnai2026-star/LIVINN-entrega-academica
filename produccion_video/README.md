## Criterios

- Usar textos grandes, pocas escenas y un solo mensaje por anuncio.
- No presentar disponibilidad, pagos o reservas como automáticos.
- Explicar que las fechas se consultan y se confirman por WhatsApp.
- No afirmar que Google Sheets está conectado directamente a la web.
- Mostrar automatizaciones o bases de datos sólo si están funcionando y pueden demostrarse.
- No incluir contraseñas, códigos, conversaciones privadas ni datos sensibles.

## Flujo rápido recomendado

1. Crear en Gemini o Flow con Veo clips verticales de 8 segundos a partir de las imágenes aprobadas.
2. Agregar textos, logotipo y CTA en el editor, no dentro de la generación, para conservar legibilidad y consistencia.
3. Grabar con OBS el recorrido real de la web, WhatsApp y las automatizaciones verificadas.
4. Editar primero las tres publicidades y luego reutilizar las mejores tomas en el video de cuatro minutos.
5. Grabar la narración final cuando el montaje esté ordenado.
6. Revisar textos, nombres del equipo y afirmaciones técnicas antes de exportar.

Para avanzar rápido, Gemini sirve para generar cada clip. Flow es preferible cuando se necesite más control sobre formato vertical, imágenes de referencia, primer y último fotograma o continuidad. El video explicativo para Raúl debe construirse con grabaciones reales en OBS y un editor convencional; la generación por IA se reserva para recursos ambientales o transiciones claramente decorativas.
